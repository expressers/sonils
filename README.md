# SONILS: redesign do website institucional

Propostas de home page para a SONILS (Sonangol Integrated Logistics Services), por Expressers.

- `/` índice das propostas
- `/a` Relatório Anual
- `/b` Planta da Base
- `/c` Fachada

## Stack

React 19 + Vite + TypeScript, Bun, GSAP (ScrollTrigger), Lenis, Phosphor Icons, Archivo (variável, eixo de largura). Deploy estático no Render (`render.yaml`).

```bash
bun install
bun run dev
bun run build
```
